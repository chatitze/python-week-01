## Projects

### Shopping List App

A command-line shopping list application built with Python.

The application allows users to:

* View the current shopping list
* Add new items with quantities
* Increase the quantity of existing items
* Remove items
* Validate user input
* Handle invalid quantities without crashing
* Navigate through a simple menu until they choose to exit

The application was initially built as a single program and then refactored into separate functions to make the code easier to read and reuse.
